BETA INSTALL GUIDE

From download to first take.

VoiceCue 1.1.0 is a beta for Apple Silicon Macs running macOS 13+. It includes the local speech engine, so there is nothing else to install.

  1. 01
    Open the disk image

    Download VoiceCue-1.1.0.dmg, then open it from Downloads.

  2. 02
    Move VoiceCue to Applications

    Drag the VoiceCue app into your Applications folder before launching it.

  3. 03
    Approve this beta once

    In Applications, Control-click VoiceCue, choose Open, then choose Open again.

!

Why the extra first-launch step? This beta is ad-hoc signed and not notarized. The macOS warning is expected; a public release still requires Developer ID signing and Apple notarization.
